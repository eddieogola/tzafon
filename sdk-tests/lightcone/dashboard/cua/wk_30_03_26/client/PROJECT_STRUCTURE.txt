API Endpoints:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. GET /api/results
   → List all verification summaries
   → GET /api/results?id={id}
   → Get specific summary by ID

2. GET /api/screenshots
   → List all screenshots with metadata

3. GET /api/logs
   → List all log files
   → GET /api/logs?file={file}&page={p}&limit={l}
   → Read log file with pagination
